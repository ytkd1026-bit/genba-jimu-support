# 01. 分類コード規格

AI棟梁 運用規格 Ver1.0 / 分類：JIMU

すべての成果物（資料・タスク・ブランチ・ドキュメント・データ）は、
下記3分類のいずれかに属させる。分類は命名規則（02）とタスク管理の起点になる。

## 分類コード一覧

| コード | 対象領域 | 具体例 |
|--------|----------|--------|
| **REVO** | 経営・事業計画・単価表・保険修繕 | 事業計画書、資金計画、単価表マスタ、保険修繕フロー、粗利分析、料金表 |
| **AIT** | AI棟梁・施工ノウハウ・現場DB | 施工事例、職人ノウハウ、歩掛データ、現場写真DB、AI学習用データセット、精度検証結果 |
| **JIMU** | 現場の事務サポ開発 | このアプリの機能追加・不具合修正・画面設計・テスト・運用手順 |

## 分類の判断基準

「その成果物が**最終的にどの事業の価値になるか**」で決める。

- アプリのコード・画面・テスト → **JIMU**
- 単価・粗利・料金・経営数値・保険 → **REVO**
- 施工の知見・現場写真の蓄積・AIの学習 → **AIT**

## 分類が重なる場合

主分類を1つ選び、必要なら本文中で従分類に言及する。
ファイル名の先頭コードは**主分類のみ**とする。

例：事務サポに単価表を組み込む機能
- コードとして作る作業 → `JIMU`
- 単価そのものの定義・改訂 → `REVO`
→ 開発チケットは `JIMU`、単価マスタ資料は `REVO`。

## 運用メモ

- 分類コードは**大文字固定**（REVO / AIT / JIMU）。
- 新しい事業分類が必要になった場合は、この規格（Ver を上げる）で追加する。
  勝手にコードを増やさない。
