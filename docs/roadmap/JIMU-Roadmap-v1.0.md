# JIMU-Roadmap-v1.0 — 現場の事務サポ ロードマップ

AI棟梁 運用規格 Ver1.0 / 分類：JIMU / 版：v1.0 / 作成：2026-07-12

事務サポを土台に、職人30人 → 元請機能 → 大量案件 → AI棟梁公開判定へと段階的に育てる。
**各 Phase は前 Phase の「移行条件」を満たすまで次へ進まない。**

---

## Phase1：事務サポ完成

**目的**：一人親方〜少人数で、案件登録から見積・請求・帳票までを
スマホ（iPhone Safari 主戦場）で完結できる状態。

主な範囲：
- 案件一元管理（案件データが本体・帳票は案件データから生成）
- 案件登録 → 現地調査 → 写真台帳 → 工事項目・原価 → 見積 → 請求 → 作業報告
- 税区分・税率対応、見積の版管理、請求スナップショット
- 入力消失を防ぐ下書き保護（debounce ＋ 離脱時フラッシュ保存）
- 実機（Mac/iPhone Safari）で安定動作する開発環境

**Phase1 完了条件**：
1. `npm run build` / `npx tsc --noEmit` 成功
2. 通常案件・保険案件の通しテスト合格
3. 見積版管理・請求スナップショットの不変性を確認
4. 税計算（税率グループ別・合算後 Math.floor）の正しさを確認
5. 全帳票 PDF の実物目視（文字化けなし・原価は提出用に出ない）
6. スマホ幅 375/390/430px で破綻なし
7. 実機 iPhone Safari で入力消失が起きない
8. 既存データ互換（旧キー非破壊）

---

## Phase2：職人30人

**目的**：現場の職人が各自のスマホで作業報告・写真登録を行える体制。

主な範囲：
- ユーザー／権限（管理者・職人）の概念導入
- 作業報告・写真台帳の職人入力フロー
- 案件の割り当て（誰がどの現場か）
- データの共有（端末ローカルから共通DBへ）※07 のギャップ解消が前提

**Phase2 移行条件**：
1. Phase1 が実運用で安定（重大不具合ゼロが一定期間継続）
2. 共通DB（例：Supabase）への移行方針確定
3. 認証・権限・データ同期の設計完了
4. グローバル一意ID（UUID）・tenant 概念の導入（07 参照）

---

## Phase3：元請機能

**目的**：自社が元請として、協力会社・下請へ発注・管理できる。

主な範囲：
- 複数事業者（自社・協力会社）の管理
- 発注・受注、下請への作業割り当て
- 元請視点の原価・粗利集計（提出用と内部用の厳密な分離を維持）

**Phase3 移行条件**：
1. Phase2 の共有・権限が安定運用
2. 事業者マスタ・発注データモデルの確立
3. 原価・粗利の可視範囲（ロール別）を制御できる

---

## Phase4：案件1000件

**目的**：データ量・運用が実務規模に達する。**AI棟梁の内部評価を開始できる最初の節目。**

主な範囲：
- 大量案件でのパフォーマンス・検索・一覧最適化
- データ品質の担保（必須項目・整合性チェック）
- AI棟梁：**内部評価のみ開始**（UI 非公開のまま、蓄積データで学習・検証の試行）

**節目条件**：
- 累計案件 **1000件** 到達
- AI棟梁の内部評価を開始（外部露出なし）

---

## Phase5：案件3000件

**目的**：AI棟梁の**精度検証**を行う。

主な範囲：
- 見積・単価・施工ノウハウの AI 提案精度の検証
- 実績との突合（提案 vs 実際の原価・粗利）
- 精度指標の定義と測定

**節目条件**：
- 累計案件 **3000件** 到達
- AI棟梁の精度検証を実施（合否基準を満たすか評価）

---

## Phase6：案件5000件 — AI棟梁公開判定

**目的**：AI棟梁を公開してよいかを判断する。

主な範囲：
- 精度・安全性・データ充足の総合評価
- 公開する場合の UI/導線・利用条件の設計（判定後）

**AI棟梁公開条件**：
1. 累計案件 **5000件** 到達
2. Phase5 の精度検証で合格基準を満たす
3. データの網羅性・整合性（07 のギャップが解消済み）
4. 誤提案時の安全策（人間の最終確認フロー）が用意されている
5. 事務サポ本体が完成し安定している

---

## AI棟梁 公開に関する厳守事項（全 Phase 共通）

- 事務サポ完成前は AI棟梁を UI/メニュー/β表示のいずれにも**出さない**。
- 案件1000件までは内部評価もしない（データ蓄積とデータ設計の先行整備のみ）。
- 公開可否は案件5000件・精度検証合格をもって**人間が判断**する。
