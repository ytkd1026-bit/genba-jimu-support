# 開発履歴（過去ワーク一覧）

「現場の事務サポ」（REVO 現場事務支援アプリ）のこれまでの開発の流れを、時系列でまとめたもの。
コミット履歴（`git log`）から再構成している。

## 第1期：帳票の土台づくり（2026-05-29〜05-31）

- Next.js プロジェクト初期化（f73b0a2）
- 見積PDF・保存用PDF・請求PDF（単体/一括・改ページ・郵送対応）を実装
- 案件登録・案件詳細（進捗管理）・月次収支・スケジュール（材料発注アラート）画面を追加
- 事業者設定画面を追加し、localStorage 保存＋各PDFへ反映
- ホーム画面を案件検索中心に整理、未請求一覧を追加
- デモ用固定データを demo モード限定化、検索共通化と案件修正履歴を追加

## 第2期：スキャン・OCR・AI整理（2026-05-31〜06-01）

- スキャン機能初期版・プレビュー・テストモードを追加
- スキャン画像OCRと種別ごとの下書き保存・一覧管理を追加
- OCR前処理、OCR結果のAI整理カード・候補選択・分類と誤反映防止を実装
- OCR文字のAI整理API（`/api/ai/structure-ocr`）、画像直接AI読取（`/api/ai/vision-structure`）を追加

## 第3期：保存安全化（2026-07-06）

- 自動下書き保存（`useAutoDraft`）・PDF発行前本保存・文字潰れ修正
- 見積・請求書の保存安全化と主要入力画面の自動下書き保存
- 開発コマンド一覧（→ [SOP: command-cheatsheet](../03-sop/command-cheatsheet.md)）を整備
- ホーム導線整理と案件・材料保存機能を追加
