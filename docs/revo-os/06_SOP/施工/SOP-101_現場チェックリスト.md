## 🎒 出発前（会社・倉庫で）

- [ ] クロス現物の**品番・ロット**が注文書と一致
- [ ] 数量OK（足りない現場が一番最悪）
- [ ] 糊・パテ・ジョイントコーク（同系色）
- [ ] カッター＋**替刃たくさん**・地ベラ・撫でバケ・ローラー・竹ベラ
- [ ] パテベラ・ペーパー・スポンジ・バケツ（**水も持参**）
- [ ] 養生シート・マスカー・養生テープ・脚立・ドライバー
- [ ] 掃除機・ゴミ袋・スマホ充電OK

## 🏠 現場に着いたら（施工前）

- [ ] あいさつ「REVOの〇〇です。本日クロスの張替えに来ました」
- [ ] やる部屋・範囲を**お客様と指差し確認**
- [ ] 📷 施工前写真: 全景4方向＋品番ラベル
- [ ] 家具移動（お客様の物は一声かけてから）・床と家具を養生
- [ ] コンセント・スイッチのフタ外し

## 🚨 剥がしたら下地チェック（ここが分かれ道）

- [ ] カビ・黒ずみ → **ない** ／ あるなら📷撮って**会社へ電話・作業停止**
- [ ] 水にぬれた跡 → **ない** ／ あるなら📷撮って**会社へ電話・作業停止**
- [ ] 大きな穴・ボード割れ → **ない** ／ あるなら📷撮って**会社へ電話・作業停止**
- [ ] 📷 剥がし後の下地全体を撮った

## 🔨 施工中（コツ4つだけ思い出す）

- [ ] パテ → 乾かす → ペーパーで平らに（📷 パテ後を撮る）
- [ ] 1列目の前に**垂直の基準線**を出した
- [ ] 糊付け後の**置き時間5〜10分**を守った
- [ ] 空気は**真ん中→外**へ追い出した
- [ ] つなぎ目は**ローラー**で押さえた
- [ ] 端切りは**地ベラ＋カッター寝かせる＋刃は面ごとに折る**
- [ ] 糊は**その場で**水拭きした

## ✨ 帰る前の品質チェック（1つでも✕なら直してから帰る）

- [ ] **1m離れて**つなぎ目が分からない
- [ ] 光を**ななめから**当ててふくれ・凸凹なし
- [ ] 手で撫でてベタつき・浮きなし
- [ ] 天井際・巾木際が一直線、すき間はコーク済み
- [ ] 入隅・出隅が浮いていない
- [ ] コンセントのフタ全部復旧・家具元どおり
- [ ] 養生撤去・掃除機がけ・**ゴミ全部持ち帰り**
- [ ] 📷 完成写真: **施工前と同じ4方向**＋つなぎ目アップ

## 🗣️ お客様へ報告（台本どおりでOK）

- [ ] 「一緒にご確認をお願いします」→ 一緒に見た
- [ ] 「乾くまで2〜3日、少しふくらみが見えても**乾けば自然に消えます**。1週間消えなければご連絡ください」
- [ ] 「換気をお願いします」「ゴミはお持ち帰りしました」
- [ ] 会社の連絡先を伝えた

## 📱 帰ったら（5分で終わる）

- [ ] 写真を事務サポの**写真台帳**に登録した
- [ ] **AI棟梁**に今日の学びを1行書いた（うまくいった事・失敗・想定外）
- [ ] 作業報告書を発行した
