# 06_SOP（標準化・手順書）

**「誰がやっても同じ品質」をつくる手順書の置き場所。**

## SOPのルール

- ファイル名は `SOP-番号_内容.md`
- **番号は仕事の種類で分ける**（下の表）。同じ種類の中では作った順に増やす
- 手順が変わったら、新しいファイルを作らず**同じファイル（正本）を直す**（履歴はGitに残る）
- 現場へ持ち出す1枚版は `SOP-番号_現場チェックリスト.md` として正本の隣に置く

| 番号帯 | 種類 | 置き場所 |
|---|---|---|
| SOP-001〜099 | 社内・事務・開発の手順 | このフォルダ直下 |
| SOP-101〜199 | 内装仕上げの施工手順 | [施工/](./施工/) |

## 施工SOPの共通の型（全業種この10項目で書く）

①必要な道具 → ②必要な材料 → ③施工前確認 → ④施工手順 → ⑤施工後確認 → ⑥写真撮影箇所 → ⑦よくある失敗 → ⑧失敗した時の対処 → ⑨品質チェック（完了判定基準） → ⑩お客様へ報告内容

＋ 全体フローチャート／ベテラン確認ポイント（独り立ち判定表）／現場持ち出しチェックリスト
