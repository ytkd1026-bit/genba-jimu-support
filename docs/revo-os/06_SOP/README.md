# 06_SOP（標準化・手順書）

**「誰がやっても同じ品質」をつくる手順書の置き場所。**

## SOPのルール

- ファイル名は `SOP-番号_内容.md`（例: SOP-001_開発コマンド一覧.md）
- 番号は作った順に3けたで増やす（001, 002, 003…）
- 手順が変わったら、新しいファイルを作らず**同じファイルを直す**（履歴はGitに残る）
