# 99_保管庫（アーカイブ）

**終わった作業の記録・証拠を保管する場所。**

## 保管庫のルール（大事）

1. **中身は当時のまま凍結**する。ファイル名も本文も書き換えない（歴史の証拠だから）
2. そのため、中の文章には**古いフォルダ名（例: `verification/`）がそのまま残っています**。これは間違いではなく、当時の記録です
3. 新しい資料をここに直接作らない。役目を終えた資料を**移してくる**だけ
