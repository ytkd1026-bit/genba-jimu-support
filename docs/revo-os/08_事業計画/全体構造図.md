# REVO OS 全体構造図（1ページ版）

**家の困りごとを解決する仕事を、最初から最後まで、忘れずに・速く・同じ品質でやるためのREVOの仕組み一式**

```mermaid
graph TD
  subgraph CUSTOMER["お客さん（家の困りごと）"]
    K["雨もり・故障・リフォームしたい"]
  end

  subgraph FRONT["入り口 ── お客さんと出会う"]
    M["REVO MEDIA<br/>【集客】<br/>本物の現場記録をもとに発信<br/>ホームページ・SNS・チラシ"]
    C["REVO CARE<br/>【住宅相談窓口】<br/>まずここに電話・LINE<br/>家の保健室"]
  end

  subgraph CORE["背骨 ── 仕事とお金を回す（稼働中）"]
    J["現場の事務サポ<br/>【案件管理】<br/>1案件1番号で全部つながる<br/>調査→写真→見積→施工→請求→報告<br/>書類5種はボタン1つでPDF"]
  end

  subgraph SITE["現場 ── 品質をそろえる"]
    S["SOP<br/>【標準化】<br/>誰がやっても同じ品質の手順書"]
    G["施工<br/>自社＋協力業者"]
  end

  subgraph BRAIN["頭 ── 会社が賢くなる"]
    T["AI棟梁<br/>【知識蓄積】<br/>症状→原因→直し方→学びを記録<br/>ベテランの頭を会社の財産に"]
    R["AI自動化ロードマップ<br/>【計画表】<br/>書類→読み取り→サーバー→音声<br/>→AI提案→経営集計の順に自動化"]
  end

  K --> M
  K --> C
  M --> C
  C --> J
  J --> S
  S --> G
  G --> J
  J --> T
  T --> R
  R -.仕組みを強くする.-> J
  T -.発信のネタ.-> M
  T -.提案の質を上げる.-> C

  style CORE fill:#f5e6d3,stroke:#8b5a2b,stroke-width:2px
  style BRAIN fill:#e8f0e8,stroke:#4a7a4a
  style FRONT fill:#e6eef5,stroke:#2b5a8b
  style SITE fill:#f0f0f0,stroke:#666666
```

## この1枚の読み方

| 場所 | 部品 | ひとこと | 状態 |
|---|---|---|---|
| 入り口 | REVO MEDIA | 知ってもらう | 1年目に本格開始 |
| 入り口 | REVO CARE | 相談にのる | 1年目に窓口開設 |
| 背骨 | 現場の事務サポ | 仕事とお金を管理 | **すでに稼働中** |
| 現場 | SOP | 手順をそろえる | 第1号あり・1年目に10本へ |
| 頭 | AI棟梁 | やり方を貯める | 器は設計済み・1年目に開始 |
| 頭 | AI自動化ロードマップ | 機械にまかせる計画 | 第2段階まで完了 |

## お金と知識の流れ（要約）

```mermaid
graph LR
  A["発信"] --> B["相談"] --> C["受注 💰"] --> D["施工"] --> E["記録"] --> A
```

- **お金の流れ**: 発信 → 相談 → 受注（工事の売上）
- **知識の流れ**: 施工 → 記録 → 次の発信・次の提案がうまくなる
- **1件工事をするたびに、会社の「頭」と「集客のタネ」が増える**
