# 04_事務サポ（現場の事務サポ／案件管理）

**REVO OSの背骨。仕事とお金を1つの案件番号で管理するアプリ。すでに動いています。**

アプリ本体はこのリポジトリの `src/` にあります。ここにはアプリの設計書・履歴を置きます。
