# 07_自動化（AI自動化ロードマップ）

**「人がやらなくていい仕事」を順番に機械へ渡していく計画表。この資料が正本（マスター）です。**
（事業計画書の第5章にも同じ表の要約が載っていますが、更新するときは必ずこのファイルを先に直します）

## ロードマップ

| 段階 | 自動化すること | 状態 | 時期の目安 ★ |
|---|---|---|---|
| 第1段階 | 書類づくり（見積・請求・報告書など5帳票のPDF化） | ✅ 完了 | — |
| 第2段階 | 紙の書類の読み取り（写真を撮る→AIが内容を整理） | ✅ 完了 | — |
| 第3段階 | データを1台のパソコン保存から、安全なサーバー保管へ | 🔜 次にやる | 1年目 |
| 第4段階 | 音声入力（現場でしゃべると記録される） | 予定 | 2年目 |
| 第5段階 | AI棟梁による提案（過去事例から直し方を提示） | 予定 | 2〜3年目 |
| 第6段階 | 保険書類の自動作成・経営数字の自動集計 | 予定 | 3〜5年目 |

★の時期は仮の目安。実際の開発計画に合わせて更新する。

## 第3段階が最優先の理由

いまは全データが1台の端末の中（ブラウザ保存）にあります。
**端末が壊れるとデータが消える**ため、これが会社のいちばん大きな弱点です。
詳細は [04_事務サポ/残タスク一覧.md](../04_事務サポ/残タスク一覧.md) に記載されています。
