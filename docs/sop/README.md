# REVO SOP Ver1.1

REVO CAREを「人が増えても同じ品質で運営できる会社」にするための標準作業手順書（SOP）です。
**読む資料ではなく、運営する資料**です。合格基準は「奥様・新人事務員に資料だけ渡しても、質問なしで作業できること」。

## 使い方（PDFにする）

1. HTMLファイルをダブルクリックしてブラウザ（Chrome推奨）で開く
2. 印刷（Ctrl+P / ⌘+P）
3. 設定を確認：
   - 用紙サイズ：**A4**（全体図だけA3にすると壁貼りに最適）
   - 余白：**なし**（またはデフォルト）
   - **「背景のグラフィック」をON**（これを忘れると色が消えます）
4. 送信先を「PDFに保存」→ 保存（紙に出すときはカラープリンターを選ぶ）

## Word / PowerPoint にしたいとき

- **Word**: 上の手順で作ったPDFを Word で開く（Word 2013以降はPDFをそのまま開いて編集できます）
- **PowerPoint**: 1ページ=1スライドの構成にしてあるので、PDFの各ページを画像としてスライドに貼るか、PDF→PowerPoint変換（Acrobat等）を使う

## 運用ルール

- 最終承認者は **社長**。各表紙の承認欄にサインしてから配布する
- 内容を直したいときは：直したい箇所をメモ → 社長承認 → 修正 → **Ver番号を上げる**（例 Ver1.1 → Ver1.2）
- 現場で「このページでは作業できなかった」が見つかったら、それは資料の直しどころ。責めずにSOPを直す
